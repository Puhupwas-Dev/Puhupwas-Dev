# Contributing

This is Puhupwas Bind's GitHub profile repository. Contributions should improve the accuracy, accessibility, or usefulness of the profile and its public evidence links.

## Useful changes

- Fix a broken link, typo, confusing description, or inaccessible image.
- Add a public source for a project role or contribution.
- Correct an outdated claim or measurement, including its date and method.
- Improve the contribution and evidence documentation.

Software bugs and features belong in the repository that owns the software. Follow that project's contribution guide.

## Before opening a pull request

1. Read the relevant section and the [open-source evidence guide](docs/OPEN_SOURCE.md).
2. Keep the change focused and explain the problem it solves.
3. For factual changes, provide a public source. Preserve authorship and attribution for third-party work.
4. Preview Markdown, check links and relative paths, and include a brief validation note.
5. Do not include credentials, confidential client information, private tasks, or personal information about other people.

A project being listed as a skill, reference, fork, or tool does not establish that this profile's owner maintains it. Adoption counts, registry downloads, maintainer roles, and contributor counts need their own evidence.

## Reporting an issue

Describe the affected section, the current problem, the proposed correction, and a supporting public link if available. For software vulnerabilities in another project, use that project's security reporting process rather than posting sensitive details here.

## Review

The repository owner reviews proposed changes. A pull request is a proposal until merged; no response or acceptance time is guaranteed.
